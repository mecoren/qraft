# i18n 中英双语(zh-CN / en-US)实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 Qraft 建立可持续的中英双语基础设施并分阶段迁移,使非中文开发者可完整使用应用(工具名/搜索/设置先行,工具内文案渐进)。

**Tech Stack:** i18next + react-i18next(唯一新增依赖);JSON 资源文件;vitest 初始化桩。

创建 `src/i18n/index.ts`:

```ts
/**
 * 应用国际化核心:i18next 实例 + 非组件层可用的 t()。
 *
 * 设计要点:
 * - 资源静态打包(两语言合计 <30KB gz),无需懒加载;
 * - fallbackLng 恒为 zh-CN:en 缺失键回退中文,迁移期永不白屏;
 * - 键缺失时返回键名(i18next parseMissingKeyHandler),
 *   让遗漏在 UI 上自暴露而非抛错。
 */
import i18next, { type i18n as I18n } from 'i18next';
import zhCN from './locales/zh-CN.json';
import enUS from './locales/en-US.json';

export type Locale = 'zh-CN' | 'en-US';

export const FALLBACK_LOCALE: Locale = 'zh-CN';

let currentLocale: Locale = FALLBACK_LOCALE;

const instance: I18n = i18next.createInstance();

void instance.init({
  lng: currentLocale,
  fallbackLng: FALLBACK_LOCALE,
  defaultNS: 'translation',
  resources: {
    'zh-CN': { translation: zhCN },
    'en-US': { translation: enUS },
  },
  interpolation: { escapeValue: false },
  parseMissingKeyHandler: (key) => key,
});

/** 非组件层( store / lib / 工具函数 )使用的翻译函数 */
export function t(key: string, options?: Record<string, unknown>): string {
  return instance.t(key, options ?? {}) as string;
}

/** 当前语言 */
export function getLocale(): Locale {
  return currentLocale;
}

/** 切换语言(幂等);调用方负责持久化到 configStore */
export function changeLocale(locale: Locale): void {
  currentLocale = locale;
  void instance.changeLanguage(locale);
}

/** 供 React 层把 i18next 实例接入 react-i18next(见 Task 2 的 provider) */
export function getI18nInstance(): I18n {
  return instance;
}
```

## Phase 2 —— 目录元数据双语(独立交付批次,模式示例完整)

**范围**:tool-catalog 41 条目 name/description + 8 分类 label + search-anchors(title/description/keywords)。
**价值**:EN 用户的全局搜索与工具名首因体验;keywords 已 75% 英文,边际成本低。

**数据结构改造**(代表性代码,全部条目同构迁移):

```ts
// tool-catalog.ts 条目从:
{ id: 'uuid_generator', name: 'UUID 生成器', description: '生成版本为 1、4(GUID)和 7 的 UUID', ... }
// 改为(保留中文字面量为默认,en 移入资源文件,避免双处维护):
{ id: 'uuid_generator', nameKey: 'catalog.tools.uuid_generator.name', ... }
```

**推荐落地**(两选一,Task 内定夺):

- 方案甲(资源文件集中):组件/目录只存 key,zh 文案整体迁入 zh-CN.json 的 `catalog.tools.*`;优点单源;缺点 diff 大。
- 方案乙(就地双语字段):`name: { zh: '...', en: '...' }`,t 选择器 `pickLocalized(field)`;优点迁移 diff 最小、类型安全;缺点新增第三语言时需再改结构。

**建议方案乙**(YAGNI:两语言阶段结构成本最低),配套:

```ts
export interface LocalizedText {
  zh: string;
  en: string;
}
export function pickText(v: LocalizedText): string {
  return getLocale() === 'en-US' ? v.en : v.zh;
}
```

搜索索引构建处(search-index.ts L67-87)把 name/description 换成「zh + en 拼接索引」——**两种语言的关键词都能命中**,展示时按当前语言渲染:

```ts
indexable = `${pickText(entry.name)} ${entry.name.zh} ${entry.keywords.join(' ')}`;
```

任务拆分:T6 分类 label + LocalizedText 基建 → T7 41 条目机械迁移(en 文案翻译,每条目一行)→ T8 search-anchors 同构迁移 → T9 搜索索引双语命中 + en 抽测。
