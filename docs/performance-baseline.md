## 对标结论(2026-09-12)

- **冷启动**:DevToys 类应用普遍 300ms–1.5s(Electron 壳普遍 >500ms);qraft 热缓存 164ms(Tauri 原生壳 + Vite 产物),处于同类工具箱第一梯队。
- **工具执行**:小输入 23.6µs(Rust 直执行),同类工具箱(DevToys/CyberChef 等 Web 内计算)普遍在毫秒级——qraft 快 1–2 个数量级;1MB JSON 格式化 38.9ms,10MB 线性外推 ~390ms 优于 PRD 500ms 上限,与 VSCode 内置格式化(serde_json 量级)同水位。
- **IPC 路径**:1MB 输入全路径(授权/执行/历史/序列化)17.9–28.8ms,PRD「1MB <50ms」达标;高频小输入 ~0.6–0.8ms,交互无感。mimalloc 全局分配器 A/B 实测冷启动/空闲 CPU 与系统分配器持平,常驻 +2.8MB(free-list 预热),远低于 150MB 预算,保留启用。
- **内存**:主进程 33MB + WebView2 渲染 ~350MB 合计,与同类 WebView2/Electron 工具箱(普遍 400–800MB RSS)持平或更低;PRD 口径仅主进程,达标。
- **回归门禁**:冷启动 +20ms / criterion 或 bench >10% 退化时,须在 PR 说明原因并回填本表。

## 回归规则

- PR 不允许冷启动增加 >20ms(prd/17-dev-workflow.md:580)。
- criterion / vitest bench 结果出现 >10% 退化时告警(prd/11-testing-strategy.md:368)。
